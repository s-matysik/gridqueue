Grid connection registers, as data you can use

Network operators across the European Union must publish the connection capacity available at each node, at least quarterly. Most publish it as documents built for printing. Drop one below and get harmonised rows back, with no installation and no upload.

Your document never leaves this computer. The page loads the real gridqueue package into a Python interpreter compiled to WebAssembly and runs it locally. There is no server to upload anything to. It is the same package, at the same version, that produced the results in the accompanying article, so what you see here matches the command line output by construction.

The disclosures are produced by commercial undertakings discharging a statutory duty, their status for redistribution is unsettled, and publishers replace them at least quarterly, so a bundled copy would misrepresent the register within months. Quality rules

Every rule returns a count, never an exception. A violation is a property of the disclosure, not a fault in the software, which is why the count is reported rather than raised.

What this page will not do

It handles one document at a time. It does not geocode, because the gazetteer is too large to send to a browser, does not compare editions over time, and does not export Parquet. For those, install the package with pip install gridqueue, or open the Colab notebook, which reproduces the longitudinal analysis from the article and stops if the figures disagree with the published ones.
