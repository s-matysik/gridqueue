gridqueue in the browser

Turn a statutory grid-connection disclosure into a harmonised, row-level table, without installing anything.

Nothing leaves your computer. The page loads the real gridqueue Python package into a WebAssembly interpreter and runs it locally. Your document is never uploaded: there is no server to upload it to. This is the same package, at the same version, that produces the results reported in the accompanying article, so the output here is identical to the command-line output by construction.

Why no sample document is bundled here. The disclosures are produced by commercial undertakings discharging a statutory duty, their status for redistribution is unsettled, and publishers replace them at least quarterly, so a bundled copy would misrepresent the register within months. Fetch a current edition from the publisher instead; the nine supported publishers are:
  • PL · PSE
  • PL · TAURON Dystrybucja
  • PL · ENERGA-OPERATOR
  • PL · Stoen Operator
  • PL · Boryszew Green Energy&Gas
  • ES · e-Distribución
  • IE · ESB Networks
  • PT · E-REDES
  • GB · National Grid

What this page does not do

It runs one document at a time. It does not geocode (the gazetteer is too large to ship to a browser), does not compare editions over time, and does not export Parquet. For those, install the package: pip install gridqueue, or open the Colab notebook, which reproduces the article's longitudinal analysis and asserts agreement with the published numbers.
