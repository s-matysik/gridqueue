Grid connection registers, as data you can use

Network operators across the European Union must publish the connection capacity available at each node, at least quarterly. Most publish it as documents built for printing. Drop them below and get harmonised rows, quality checks, analyses and charts back, with no installation and no upload.

Your documents never leave this computer. The page loads the real gridqueue package into a Python interpreter compiled to WebAssembly and runs it locally. There is no server to upload anything to. The charts are drawn by the same gridqueue.plots functions as on the command line and in the notebook, from the same numbers, so they match by construction.

The synthetic data are generated by gridqueue.examples and describe no real grid.

No sample document ships with this page. The disclosures are produced by commercial undertakings discharging a statutory duty, their status for redistribution is unsettled, and publishers replace them at least quarterly, so a bundled copy would misrepresent the register within months. Fetch a current edition from the publisher instead.

Result

    Charts

      Two editions

      Status transitions among linked rows: rows are the earlier edition, columns the later one.

      Analyses

      Time from application to connection conditions, per resource class (Kaplan-Meier, open applications censored at the as-at date, 95% Greenwood interval of the median).

      Node loading: requested capacity of the active queue over the declared free capacity. Undefined where the publisher declares zero free capacity.

      Quality, validation and column shift

      Every rule returns a count, never an exception. A violation is a property of the disclosure, not a fault in the software, which is why the count is reported rather than raised.

      Column shift audit, audit_column_shift

      Parse report

      Returned verbatim by each adapter call, including whatever it could not resolve.
